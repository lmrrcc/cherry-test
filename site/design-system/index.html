Design system

Quiet surfaces, loud results

A no-build CSS system for developer tools: two files, tokens.css and components.css. Neutral 12-step scales in the Radix Colors model, one accent, and pass / fail / warn reserved for test outcomes. Set in Geist and Geist Mono. Every token flips for dark mode.
